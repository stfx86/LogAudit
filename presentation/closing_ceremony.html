CVE-2022-30333
UnRAR Path Traversal Attack

For this demonstration, we exploited CVE-2022-30333, a vulnerability in the UnRAR utility that allows an attacker to write files outside the intended extraction directory. By crafting a malicious RAR archive and delivering it to a vulnerable target, we were able to gain unauthorized access to the system. The entire attack was carried out using the Metasploit Framework, which provided a ready-made module to automate the exploitation process from generating the payload to establishing a remote session on the victim machine.
